# Family tree in C language

The file family_tree.c implements a family tree in c code using sturctures and pointers. It stores information about seven family memembers, yours, your parents and their parents age and name.

# Features

some features include creating records using memory allocation, linking the parents using pointers and displaying their name and age.

# Compiling

How to compile in bash 

gcc family_tree.c -o family_tree
